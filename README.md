# Delta Free Media — Application Portal

Разработан современный, высокооптимизированный веб-портал для подачи заявок **Delta Free Media** на языке **Go** с использованием фреймворка **Fiber** и встроенного хранилища SQLite.

---

## 🌟 Основной функционал

1. **Заявки для пользователей (Медиа команда)**:
   - Проверка соответствия критериям с интерактивным модальным окном критериев.
   - Выбор платформы (**YouTube** или **TikTok**) с динамическим раскрытием дополнительных вопросов.
   - Кастомный мультивыбор серверов (**Funtime, Spookytime, Reallyworld, Holyworld, Прочие**) с выведением списка непосредственно в строку dropdown и поворотом стрелочки.
   - Обязательная валидация всех полей (ссылки, Telegram `@username`, количество роликов/сострудничества, мотивация, эксклюзивность).

2. **Заявки для модераторов (Сброс HWID и Discord баны)**:
   - Скрыты при обычном входе на сайт.
   - Активируются сочетанием клавиш `Ctrl + M` и вводом секретного ключа модератора.
   - Поддерживается доказательство файлом (скриншот/видео) **ИЛИ** внешней ссылкой.
   - Для подачи заявки используется уникальный **Модер-ключ**, привязанный к никнейму модератора.

3. **Скрытая админ-панель**:
   - Активируется сочетанием клавиш `Ctrl + Shift + A` и вводом пароля администратора.
   - Отображение сводной статистики (всего заявок, в ожидании, количество активных модераторов).
   - Управление заявками медиа, сбросом HWID и Discord банами (одобрение/отклонение с комментарием).
   - Создание и управление **Модер-ключами** (генерация уникального ключа для никнейма, активация/деактивация/удаление).

4. **Telegram Уведомления (Bot & Business API)**:
   - Автоматическое уведомление администратора в Telegram при поступлении новой заявки.
   - Автоматическая отправка вердикта (Одобрено/Отклонено) в Telegram пользователю или модератору.

5. **i18n Мультиязычность**:
   - Поддержка маршрутов `/ru` и `/en`.
   - Мгновенное переключение языка в шапке без перезагрузки и потери данных формы.

6. **Максимальная оптимизация**:
   - Минимальное потребление памяти в простое благодаря агрессивному GC (`GOGC=20`), ограничениям пула соединений SQLite и zero-allocation архитектуре Fiber.

## 🎨 Дизайн и Стиль

Дизайн разработан в стиле проекта **wetid**:
- Элегантная тёмная тема (`#0e0d0b`), плашки карточек с эффектным размытием backdrop-filter.
- Премиальная типографика (**Inter**, **Outfit**).
- Фиолетовые (`#a855f7`) и коралловые акценты, подсвечивающиеся границы.
- Плавные анимации появления модальных окон и выпадающих списков.
- Геометрический SVG-логотип "Delta Free Media".

## ⚡ Запуск и Использование

### Сборка приложения:
```powershell
go build -v -ldflags="-s -w" -o delta-portal.exe .
```

### Запуск:
```powershell
.\delta-portal.exe
```
По умолчанию приложение доступно по адресу: `http://localhost:3000`

### Секретные сочетания клавиш:
- `Ctrl + M` — Вход для модераторов (Тестовый ключ: `DELTA-MOD-DEMO`)
- `Ctrl + Shift + A` — Панель администратора (Тестовый пароль: `admin123`)
